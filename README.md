# 一箭又一箭 (Arrow Puzzle)

> 点击式箭头解谜小游戏 —— 使用 Python + Pygame 开发, 借助 AIGC(Claude Code)辅助完成
> 《Python 程序设计》课程作业

## 项目简介

"一箭又一箭"是一款规则简单、上手即玩的休闲解谜小游戏。棋盘上散布着上、下、左、右四个方向的箭头:

- 点击一个箭头, 如果它前进方向(同一行/同一列)到棋盘边界之间**没有其他箭头**, 它就会飞出棋盘并被消除;
- 如果路径上有其他箭头**阻挡**, 箭头无法飞出, 并消耗一次失误机会(同时播放碰撞动画: 撞击回弹 + 晃动 + 变红 + 飘字);
- **清空本关全部箭头即可过关**; 失误次数耗尽则本关失败, 可重新开始。

游戏共 8 个关卡, **全部为长箭玩法**: 每支箭头横跨多个格子、可以在中间拐弯; 点击箭身任意位置选择它; 头部前方到边界之间无其他箭头即可飞出, 长箭会沿自身轨道滑出棋盘。**箭头颜色用于区分相邻箭头**(贪心图着色, 相邻箭头尽量不同色, 每关至少 3 种颜色, 色板为 →蓝 ←绿 ↑橙 ↓紫)。基础判定规则(单格箭头的同行/列路径检测)保留在代码中, 由单元测试覆盖。第 1~2 关为入门关卡(5×5), 第 5~8 关为满格关卡(36/36 个格子全部被箭头占据)。全部关卡都经过自动化解算验证, 保证存在通关顺序。

## 开发环境

| 项目 | 说明 |
| --- | --- |
| 操作系统 | Windows 11 |
| Python | 3.14.5 |
| 图形库 | pygame-ce 2.5.8(Pygame 社区版, API 与官方 pygame 完全兼容, `import pygame` 用法不变) |
| 字体 | 系统自带微软雅黑(msyh.ttc) |

> 注: 官方 pygame 暂无 Python 3.14 的 Windows 预编译包, 因此选用提供 cp314 wheel 的 pygame-ce。
> 界面全部由代码绘制, 无需任何外部图片/音频素材。

## 安装与运行

```bash
# 1. 安装依赖(项目根目录下)
pip install -r requirements.txt

# 2. 运行游戏
python main.py        # 或 py main.py
```

## 游戏操作

- **鼠标点击箭头**: 尝试让箭头飞出棋盘(长箭点击身体任意位置);
- **重新开始按钮**(右上角): 将当前关卡恢复到初始状态;
- **撤销按钮**: 回退上一步(恢复最近一次飞出前的局面);
- **提示按钮**: 高亮一个当前可飞出的箭头(约 2.5 秒);
- **自动求解按钮**: AI 自动演示本关通关步骤, 点击任意位置可打断;
- **ESC 键**: 随时返回主菜单;
- **自动存档**: 通关进度、历史星级与当前对局自动保存到本地 save.json(开发环境在项目目录, 打包后在 exe 同目录); 主菜单"继续游戏"可恢复上一次对局;
- 顶部信息栏实时显示: 当前关卡、剩余箭头数量、用时、剩余失误机会(圆点);
- 通关结算显示星级(★, 按剩余失误次数评定)与用时, 历史最佳星级记录在关卡选择界面。

## 关卡设计

| 关卡 | 名称 | 棋盘 | 箭头数 | 特点 |
| --- | --- | --- | --- | --- |
| 1 | 初试身手 | 5×5 | 4 | 入门, 长箭规则上手 |
| 2 | 小试牛刀 | 5×5 | 6 | 拐角长箭 + 两条短链 |
| 3 | 渐入佳境 | 6×6 | 7 | 三连解锁链 |
| 4 | 环环相扣 | 6×6 | 9 | 四连解锁链 |

| 6 | 进阶·初识拐角 | 6×6 | 10 | **满格 36/36**, 乱序长蛇(13 个弯) |
| 7 | 进阶·曲径通幽 | 6×6 | 10 | **满格 36/36**, 乱序长蛇(9 个弯) |

## 拓展功能

- **关卡选择**: 主菜单进入, 1~8 关 + "无限挑战", 显示历史最佳星级;
- **星级评价 + 计时**: 通关后按剩余失误次数评 1~3 星, HUD 实时计时;
- **提示**: 高亮一个当前可飞出的箭头;
- **AI 自动求解**: 复用贪心解算器, 一键演示通关步骤;
- **撤销上一步**: 快照-恢复机制, 可回退多步;
- **无限挑战**: 随机生成关卡——采用"逆向出题法"(按移除顺序的逆序放置箭头), 生成的每一关都必然可通关;
- **保存游戏进度**: 本地 JSON 存档(save.json), 自动保存解锁进度/星级/当前对局(含随机关卡与撤销栈), 主菜单可"继续游戏";
- **合成音效**: 飞出/碰撞/通关/失败四种音效由程序合成(标准库 struct/math 生成音频字节), 无需外部素材, 无音频设备时自动静音;
- **打包为可执行文件**: 见下方"打包 exe"。

## 打包 exe

```bash
pip install pyinstaller
py -m PyInstaller --onefile --windowed --name "一箭又一箭" main.py
```

生成的可执行文件位于 `dist/一箭又一箭.exe`, 双击即可运行, 无需安装 Python。

## 项目结构

```
arrow-game/
├── main.py            # 程序入口
├── game.py            # Pygame 界面: 画面状态机、动画、按钮
├── logic.py           # 核心逻辑: 路径检测、点击判定、关卡状态(与界面解耦, 便于测试)
├── levels.py          # 5 个关卡数据
├── settings.py        # 全局常量(窗口、颜色、棋盘尺寸)
├── sounds.py          # 合成音效(无外部素材)
├── save.py            # 进度存档(本地 JSON)
├── tests/             # 单元测试(26 个用例)
├── tools/             # 自动试玩脚本、截图生成脚本
├── screenshots/       # 游戏截图
└── docs/              # 测试记录、AIGC 使用记录
```
